# 国旗改用 SVG 图片（修复 Windows 不显示 emoji 国旗）

**原因**：国旗 emoji 在 Windows 上无字体支持，渲染为字母对（如 CN），仅 macOS/iOS/Android 可显示。改为 SVG 图片后全平台一致。

**改动**：

1. **新增依赖 `flag-icons`**（npm，MIT 许可，纯 SVG 旗帜素材包，无 JS 运行时）——只用其中 19 面旗帜的 SVG 文件，Vite 按引用打包，产物增量约几十 KB。属于素材包而非框架，符合 §7 精神；如你不想加依赖，备选方案是手工下载 19 面 SVG 入 `src/assets/flags/`（多一道下载工序，效果相同）

2. **`src/views/Contact.vue`**：
   - `import` 19 面 `flag-icons/flags/4x3/{iso}.svg`（cn/hk/mo/tw/sg/my/jp/kr/th/vn/in/ae/eg/de/fr/gb/us/au/br）
   - `regions` 每项 `flag` 字段由 emoji 字符串改为导入的 SVG URL，另加 `iso` 字段备用
   - 下拉选项与选中态把 emoji `<span>` 换成 `<img :src="r.flag" class="phone-region__flag-img">`（高 14px、圆角 2px、边框 1px 淡色防白边旗帜隐形）
   - 其余逻辑（校验、合并提交、19 国列表）不动

3. **验证**：build → preview 确认下拉与选中态 19 面旗帜图片全部加载（network 无 404）、校验回归（+86/+1 各分支）不受影响、375 不破版 → 更新记忆库 → 提交推送

**备选（不推荐）**：保留 emoji 不动——Windows 访客（你的主力用户群）永远看不到国旗。
