# 电话地区选择器：同区号国家分列 + 支持自定义区号

## 改动（均在 `src/views/Contact.vue`）

**1. 美国/加拿大分列（同区号不合并）**
- 新增 `flag-icons/flags/4x3/ca.svg` 导入
- 列表拆成「美国 +1」「加拿大 +1」两条（共 20 项）
- 结构性调整：条目加唯一 `iso` 字段，`el-option` 的 key/value 改用 `iso`（+1 有两条，原来用 code 当 value 会撞 key 且无法区分选中项）；下拉筛选 label 改为当地语言国名（支持输入国名过滤）
- `phoneRegion` 改存 iso（默认 `'cn'`），新增 computed：`selectedRegion`（按 iso 查对象）、`regionCode`（选中条目的区号）

**2. 未 listed 的国家可自填区号**
- el-select 加 `filterable allow-create default-first-option`：在框内直接键入如 `+974` 或 `974` 回车即创建为自定义区号
- 选中项无对应国家对象时（自填场景）：不显示国旗、显示归一化后的区号（无 `+` 自动补 `+`）
- 自定义区号的号码校验走通用国际规则（非 0 开头 5–14 位）；自填 `+86` 也享受大陆详细校验，逻辑自洽
- 提交值仍为「区号 + 号码」合并（如 `+974 12345678`），影子表单不动

**3. 验证**：build → preview 实测：美国/加拿大两条独立可选且选中态各自显示；输入 `+974` 创建、显示 `+974`、配通用校验；原 19 国回归（+86/自定义分支、提交合并值）；1280/375 不破版。完成后更新记忆库并提交推送。
