# 地区选择恢复下拉框（51 国不合并）+ 保留手动键入

## 设计（合并前两版能力）
- **prepend 换回 el-select**：`filterable`（键入国名即可过滤，如输「马来」快速定位）+ `allow-create`（键入未收录区号如 `+233` 回车可创建）+ `default-first-option`
- **51 国全部平铺为选项，同码国家不合并**：美国 +1、加拿大 +1 各自独立（选中哪个显示哪国国旗）；选项布局「国旗 + 国名 + 区号」
- **选中态**：国旗 + 区号（如 🇺🇸 +1）；自填区号无匹配国旗时只显示归一化区号
- **键入区号的国旗自动匹配保留**：自填 `+44` 若与表中英国同码 → 显示英国旗；区号格式非法仍报 `codeRule`
- 键入/选择变化时联动重校验号码（沿用现有逻辑）；提交合并值不变

## 改动（均在 `src/views/Contact.vue`）
1. 模板：区号区段从「input + 自控菜单」换回 el-select（选项来自 `src/data/dialCodes.js`）
2. 脚本：`phoneRegion` 存 iso（默认 'cn'）；`selectedRegion`/`normalizedDial`/`matchedIso`/`flagUrl` computed；`onMounted` 预加载全部 51 面旗帜（下拉展开即有图）；删除 flagOpen/onDocClick/pickCandidate/onDialBlur 等自控菜单逻辑
3. 样式：`.dial-code*` 换回 `.phone-region*`（select 宽 150px、选项/选中态排布）
4. i18n 无新增 key
