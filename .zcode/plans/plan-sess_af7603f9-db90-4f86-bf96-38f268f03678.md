# 日历年月标题放大

**改动**：`src/views/News.vue` 的 `.mini-cal__ym` 增加字号——

```css
.mini-cal__ym {
  font-weight: 700;
  font-size: clamp(17px, 1.4vw, 21px);   /* 新增:当前继承正文 ~16px */
  color: var(--c-primary-dark);
  letter-spacing: 1px;
}
```

用 `clamp()` 流式字号（符合弹性布局规范）：手机 ≈17px、桌面最大 21px，比现在放大约 1/3，视觉居中更突出。左右切换按钮、星期行、日期格不动。

**验证**：`npm run build` → preview 在 1280 与 375 视口截图确认效果与不破版 → 更新记忆库（activeContext）→ 提交推送。
