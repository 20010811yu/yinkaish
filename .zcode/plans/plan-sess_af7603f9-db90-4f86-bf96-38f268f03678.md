# 区号自行输入 + 自动匹配国旗（同码多国可自选旗帜）

## 设计
- **区号输入框**（替换原下拉）：键入 `+86` / `86`，自动归一化并校验格式（1–4 位数字、非 0 开头）
- **自动匹配国旗**：在 51 国区号表（50 个区号）中查找该区号——匹配到即显示对应国旗 SVG；未收录的合法区号不显示国旗，号码走通用校验
- **同码多国自选旗帜**（+1 美国/加拿大、+7 俄罗斯/哈萨克斯坦）：输入同码后，区号框旁出现小箭头，点开弹出候选列表（国旗 + 双语国名），点击即切换显示的旗帜；默认显示第一个候选；单匹配国直接显示，无箭头
- **号码自动校验**：号码失焦时按区号校验（+86 详细规则 / 其他通用 5–14 位）；区号或候选国变更时，号码已填则自动重新校验；提交前全量兜底
