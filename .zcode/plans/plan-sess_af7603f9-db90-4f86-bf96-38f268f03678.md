# 加入我们页「申请职位」弹框（含简历附件上传）

## 现状
- `Careers.vue:77-79` 的 `apply()` 是占位（仅弹 ElMessage.info），按钮 `@click.stop="apply"` 不带职位参数
- `Contact.vue` 已有 el-form + rules + fetch POST Netlify 模式可复用（但它是 URLSearchParams 纯文本提交，文件上传需改 multipart）
- `index.html:11-17` 已有影子表单 `contact`；el-dialog/el-upload 无使用先例，但 resolver 按需引入已就绪，模板直接写即可

## 实施

### 1. `src/views/Careers.vue`
- `@click.stop="apply(j)"` 传入职位；`apply(j)` 记录 `currentJob`、打开 `dialogVisible`
- 页面末尾新增 `el-dialog`（width `min(92vw, 520px)` 弹性，关闭时 resetFields + 清空文件）：
  - 应聘职位：disabled el-input，自动带入 `pick(currentJob.title, locale)`
  - 姓名（必填）、联系电话（必填 + 宽松格式校验）、电子邮箱（选填，填了才校验格式）
  - **简历附件（必填）**：el-upload `:auto-upload="false"` + `:limit="1"` + `accept=".pdf,.doc,.docx"`，按钮式选择文件，tip 提示格式与大小
    - 类型按扩展名校验（.pdf/.doc/.docx），大小 ≤10MB（Netlify 单次提交上限），不符即 ElMessage.error 并拒绝入选
    - 已选文件再选时自动替换（on-exceed → clearFiles + 重设）
  - 个人简介 textarea（选填）
  - footer：取消 + 提交申请（:loading 防重复提交）
- 提交：el-form 校验通过后用 **FormData** fetch POST `/`（不再手动设 Content-Type，让浏览器带 multipart boundary）：`form-name=job`、position/name/phone/email/message、`resume` 字段附 File blob；成功 → ElMessage.success + 关弹框 + 重置；失败 → ElMessage.error（GitHub Pages/本地无表单后端走 fail 分支，与联系表单一致）

### 2. `index.html`
- 新增影子表单 `<form name="job" data-netlify="true" netlify hidden>`，含 position/name/phone/email/message 隐藏字段 + **`<input type="file" name="resume" />`**（Netlify 靠影子表单注册字段，文件字段缺了收不到附件）

### 3. i18n（`src/i18n/zh.js` / `en.js` 同步新增 `careers.form.*`）
- name/phone/email(选填)/message(选填)/position/resume 标签、selectFile 按钮、resumeTip（支持 PDF/DOC/DOCX，≤10MB）、resumeType/resumeSize 错误、cancel/submit 按钮、success/fail 提示；弹框标题用 `t('careers.apply') + '：' + 职位名` 拼接

### 4. 验证（P3）
- `npm run build` 通过
- preview 浏览器实测：点不同职位 → 弹框带出职位名；不选简历/空姓名提交 → 校验拦截；选 .pdf 与非 .pdf 文件 → 类型校验生效；选文件后列表显示文件名、可移除、可替换；填全提交 → multipart 请求发出（本地走 fail 提示属预期，网络面板确认 FormData 含 resume 文件）；1280/768/375 弹框不破版、无横向滚动

### 5. 收尾（P4/P5）
- 踩坑如实入 errorlog.md；activeContext/progress 更新；`git add -A` → commit → push
