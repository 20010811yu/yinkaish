# 任务：消除刷新时的深绿色大块（轮播占位体验优化）

## 已复现的根因
刷新瞬间轮播区先渲染我加的深绿兜底背景色（首图未加载完时），在首屏形成一大块深色「底部栏」，图片加载完才消失。

## 方案：模糊占位图（LQIP）替代纯色兜底
1. 用 sharp 为 5 张轮播图各生成超小模糊占位图（宽 32px JPEG，base64 内联，每张 <1.5KB）
2. `HeroCarousel.vue`：每张 slide 的 background 同时写 `高清图, 模糊占位图` 两层——高清图加载完成前先显示拉伸的模糊色块（视觉近似成图，不再是生硬深色块）；首张的 `<img>` 加载完成后淡入
3. `.slide` 的深绿兜底 background-color 改为浅色 `#e8f5ee`
4. 首图仍是 `fetchpriority="high"` 优先加载

## 验证与收尾
- 刷新连拍截图确认不再出现深色大块
- `npm run build`；P4 记忆库一行；P5 commit + push 附哈希
