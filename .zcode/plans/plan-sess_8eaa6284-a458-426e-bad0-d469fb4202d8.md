## 任务：首页动画改造（方案一 + 方案二）

### 方案一：滚动入场 + 大数字计数
1. `src/assets/styles/main.css`：全局新增 `[data-reveal]` 工具样式（进视口淡入上移 0.7s，`[data-reveal-delay]` 1-3 档错峰；包在 `prefers-reduced-motion: no-preference` 内，系统减动效时直接显示）
2. `src/views/Home.vue`：
   - 模板给首页各区块加 `data-reveal`（intro、业务卡片、优势左列/城市图、四条优势、新闻卡）+ `:data-reveal-delay` 错峰
   - script：`onMounted` IntersectionObserver 观察 → 加 `.revealed`；`.count` 大数字元素进入视口时 rAF 计数动画（解析 i18n 文本中的数字，保留前缀/后缀与小数位）；`prefers-reduced-motion: reduce` 时跳过全部动画；`onBeforeUnmount` 断开
3. `src/router` 其他页面暂不加 attr（不影响）

### 方案二：电路连线 + 城市微动效 + 视差
1. **连线描边流动**：`.adv__wire` path 用 `stroke-dasharray/dashoffset` 描边绘制（左列 revealed 后触发），端点圆点脉冲闪烁；scoped + reduced-motion 守卫
2. **城市插画微动效**：`scripts/gen-hero-city.cjs` 内嵌 SVG `<style>`（同样带 reduced-motion 守卫）——随机窗户灯 tw 闪烁、数据光柱 beam-p 缓慢升降、星点 star-t 闪烁；重跑脚本再生成 `hero-city.svg`（种子不变，构图不变）
3. **视差**：滚动时 `.adv__fig` 城市图随进度轻微 translateY（rAF 节流 + reduced-motion 跳过）

- `npm run build` + 浏览器验证：滚动触发入场、计数动画到位、连线绘制、375 无溢出、动画不破坏弹性布局
