## 任务：为首页设计一张现代科技城市主视觉图

### 方案

沿用项目既有惯例（hero-tech.svg / hero-vision.svg 均为脚本生成的程序化 SVG，品牌风格统一且无版权风险），新建生成脚本产出「现代科技城市」主视觉并接入首页轮播。

### 改动点

1. **新增 `scripts/gen-hero-city.cjs`**：生成 `src/assets/hero-city.svg`（1920×1080，种子随机可复现，纯字符串拼装无新依赖）。画面构成——
   - 深绿渐变夜空 + 底部日出光晕（品牌绿 #00a651 系）
   - 三层城市天际线（远/中/近，含楼顶天线红色航标灯）
   - 楼宇窗格灯光矩阵（绿色系随机亮灭）
   - 构图主角地标塔（玻璃幕墙渐变 + 顶部光冠天线）
   - 数据流光柱从楼群升起、电路走线数据总线
   - 透视网格地面（科技地平线）
   - 前景光伏板阵列两排（透视 + 剪影大板，呼应公司光伏业务）
   - 星点/漂浮粒子
2. **接入轮播**：`HeroCarousel.vue` 新增第 5 张 slide（追加在最后，不打乱已确认的前四张叙事），文案 i18n `home.carousel.s5`（zh「绿色智造，点亮未来之城」/ en「Green Smart Manufacturing, Lighting the City of the Future」），中英同步
3. 运行脚本生成 SVG → `npm run build` → 浏览器截图自查视觉效果
4. **P4 记忆库**：activeContext.md、progress.md 记录；**P5** 自动 add/commit/push

### 备注

生成的是矢量插画风格科技城市（与现有 hero-tech.svg 一致），非照片实拍；如需照片风格需另提供素材。轮播位置/文案后续一句话即可调整。
