# 任务：切换为 ECharts geo 地图方案

## 依赖
1. `npm i echarts`（按需引入，避免全量）
2. `npm i world-atlas topojson-client`：世界地理数据源（Natural Earth 数据，公有领域，许可干净；countries-110m.json ≈108KB TopoJSON，用 topojson-client 转成 GeoJSON 后 `echarts.registerMap('world', geojson)`）

## 实现
新建 `src/components/WorldMap.vue`（替换现有 jsvectormap 版）：
- 按需引入：`echarts/core` + `GeoComponent` + `ScatterChart` + `SVGRenderer`（矢量渲染，缩放清晰）
- `geo` 配置：map 'world'，区域填充品牌绿 `#8fdcb1`、白色国界线 0.6、禁用 hover 缩放
- `series: scatter`（coordinateSystem 'geo'）：五个标记用真实经纬度（上海 31.23,121.47 / 美国 39,-98 / 埃及 26.5,30 / 印度 22,79 / 吉隆坡 3.1,101.7），`label: { show: true, formatter: 名称, color: 品牌绿, 白描边 }`，symbolSize 12
- 标签文字走 i18n：`watch(locale)` → `setOption` 更新 label；`window.resize` → `chart.resize()`（缩放天然跟随）
- `prefers-reduced-motion` 时不用 ripple 特效（用普通 scatter，天然满足）；onBeforeUnmount `chart.dispose()`
- 地图 JSON 在模块加载时 fetch 一次并缓存（多次进页面不重复请求）

## 清理
