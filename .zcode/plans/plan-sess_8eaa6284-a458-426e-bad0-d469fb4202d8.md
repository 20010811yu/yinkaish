# 任务：修复刷新时先显示页脚再跳回顶部

## 根因（新判断，与图片体积无关）
浏览器刷新时会**自动恢复上次的滚动位置**（scrollRestoration=auto）：刷新瞬间页面被定位在底部（页脚），随后 Vue 挂载、路由 scrollBehavior 才把页面滚回顶部显示轮播——造成「先见底部栏、再见轮播图」。

## 方案
`src/router/index.js`：在创建 router 前设置 `window.history.scrollRestoration = 'manual'`，禁用浏览器原生滚动恢复，强制每次加载都从顶部开始（站内路由切换的锚点行为不受影响，scrollBehavior 仍生效）。

## 验证与收尾
- 预览页滚到页脚 → 刷新 → 断言 `scrollY === 0` 且首屏为轮播
