# 任务：消除刷新时「导航+页脚」先渲染、首页内容后出现的空窗

## 根因
路由所有页面均为懒加载（`() => import(...)`）。刷新时 App 骨架（导航+页脚）先渲染，此时 Home 分包尚未下载完，router-view 区域为空 → 页脚贴着导航栏显示；分包到达后首页内容才出现。

## 方案
1. `src/router/index.js`：首页改为**静态导入**（`import Home from '../views/Home.vue'`）——首页是绝对主要的落地页，随主包一起加载，消除空窗；其余页面保持懒加载不影响性能
2. 兜底：`src/assets/styles/main.css` 给 `#app` 设置 `min-height: 100vh`，任何页面切换瞬间也不出现「页脚贴导航」的塌陷布局

## 验证与收尾
- `npm run build`（主包体积会增大 ~50KB/gzip 12KB，可接受）；预览反复刷新目检首屏始终为轮播
