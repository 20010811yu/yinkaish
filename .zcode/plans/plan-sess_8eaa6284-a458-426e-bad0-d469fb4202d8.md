# 任务：修复首页加载时轮播图迟迟不显示（先见页脚后见图）

## 根因
首图 banner-home.jpg 2.6MB、第二张 banner-pv.png 2.35MB（PNG 未压缩），慢网络下载数秒；期间轮播区空白、其余区块处于入场动画隐藏态，视觉上「页脚先出现、轮播图最后出现」。

## 方案
1. **压缩首屏大图**（sharp，宽 2560、q80、sRGB，与 banner-car 293KB 同规格）：
   - banner-home.jpg：2.6MB → 预计 ~300KB
   - banner-pv.png → 转 banner-pv.jpg（~300KB），HeroCarousel 与 data 引用同步改
2. **首图预加载**：`index.html` 增加 `<link rel="preload" as="image">`——文件名带 hash，改用轻量方式：HeroCarousel 第一张 slide 改用 `<img>` 标签（天然高优先级+可加 fetchpriority="high"），其余仍用背景图；或直接给 slide 1 的背景层加内联样式加载。取实现最稳者
3. 轮播容器加深色兜底背景色，图片未到时不刺眼

## 验证与收尾
- `npm run build` 对比图片产物体积；预览清缓存慢速目检轮播首屏出现顺序
