## 任务：全站弹性布局改造 + 写入 AGENTS.md 规则

探索审计已完成（13 个样式文件全查）。结论：全站网格/容器基本已是 fr/max-width 弹性写法，但有 7 个必破版风险点 + 一批固定 px/断点不一致。以下为执行方案。

## 一、AGENTS.md 写入规则（第二部分 §11 追加，版本号升 v1.2）

新增「弹性布局（硬约束）」条款：
1. 布局容器一律 max-width 限宽（`--container` / 内容 max-width），禁止固定 px 宽度；多列布局必须 flex/grid，列宽用 fr/%/minmax()/clamp()，网格禁止混入 >100px 固定 px 列（小图标/小控件 ≤100px 不限）
2. 流式尺寸用 clamp()（沿用根字号 clamp 惯例）；字号优先 rem；轮播/Hero/大图等大高度用 clamp(min, vw, max) 或 aspect-ratio，禁止 ≥200px 固定高度跨屏
3. img/video 必须 max-width:100%（全局兜底，不得局部破坏）
4. 正文/详情等长文本容器必须加 overflow-wrap 防长串撑破
5. 断点统一 ≤768 / 769–1024 / >1024；每个多列与大尺寸区块必须有平板+移动端降级；全站禁止横向滚动条
6. 新增/修改样式须在 1280/1024/768/375 四档宽度自查

## 二、代码改造（按审计清单）

**必破版修复（Top 风险）**
1. `AppNavbar.vue`：品牌区 `margin-left: calc(100vw/6 - 110px)` → `max(0px, calc(...))`（<660px 不再为负）；菜单 `margin-left: 80px` → `clamp(16px, 5vw, 80px)`；内边距 `0 40px` → `0 clamp(16px, 3vw, 40px)`；链接横 padding 0.75rem→0.625rem；**抽屉菜单断点 768→1024**（7 个 nowrap 链接在 769–1100px 客观放不下，平板收起为汉堡菜单）；768 块补品牌名缩小
2. `HeroCarousel.vue`：轮播高 `780px` → `clamp(480px, 55vw, 780px)`；标题 `3.5rem` → `clamp(1.75rem, 1.4rem + 2.6vw, 3.5rem)`；装饰线 `220px` → `clamp(120px, 30vw, 220px)`；删除被 clamp 取代的 768 硬切覆盖
3. `About.vue` 荣誉大图：高 `560px` → `clamp(340px, 45vw, 560px)`；缩略图列 `190px` → `minmax(150px, 190px)`
4. `About.vue` 时间线：图高/脊线 `320px` → `clamp(220px, 30vw, 320px)`；`max-width: 60vw` 在 1024 断点放宽为 `82vw`（平板不再挤成窄条）；年份/标题/正文 38/28/20px → clamp 流式（26/19/14 为下限），删除 768 硬切

**弹性一致性（中优先级）**
5. `main.css`：`.section`/`.page-hero` 内边距 → clamp；补全局 `video { max-width:100% }`；删除被 clamp 取代的 768 覆盖块
6. `Home.vue`：统计数字/CTA 标题 px → clamp；CTA 内边距 → clamp
7. `Services.vue`：视觉块高 180px → `clamp(130px, 18vw, 180px)`
8. `AppFooter.vue`：px 字号统一改 rem；新增 1024 断点（4 列→2 列）
9. `Team.vue`：孤例断点 600px → 统一为 768
10. `Careers.vue`：福利 3 列补 1024→2 列；job__meta 加 flex-wrap
11. `NewsDetail.vue`：正文加 `overflow-wrap: anywhere`
12. `About.vue` mvv 三列补 1024→2 列

不改：≤100px 小控件（logo、日期徽章、箭头、二维码 96px）符合新规豁免。
