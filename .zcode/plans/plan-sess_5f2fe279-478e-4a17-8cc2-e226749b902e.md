# 登录输入框自动删除空格

## 需求
管理端登录页的用户名、密码输入框自动删除空格（常见于粘贴带入首尾/中间空格导致的登录失败）。

## 修改（1 个文件：`src/views/admin/AdminLogin.vue`）
- 加两个 watch：`form.username` / `form.password` 变化时把值中**所有空白字符**（含首尾与中间、全角空格）剥掉后写回——输入时即时生效，输入框内同步显示净化后的值
- 写回前判断值有变化才赋值，避免 watch 死循环
- 粘贴、键入、自动填充场景均覆盖（watch 对所有赋值路径生效）

## 验证与收尾
1. 浏览器验证：输入 ` ad min ` → 输入框显示 `admin`；粘贴带空格密码同样被净化；正常登录不回归
2. `npm run build` 通过；提交推送（小改动，记忆库无需更新）
