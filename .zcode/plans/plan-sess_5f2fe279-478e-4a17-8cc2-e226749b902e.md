# 修复：登录失败「毫无提示」的死角 + 提示信息排查结论

## 排查结论（已多轮实测）
- 后端正常、登录接口 401 正常返回；**新代码在干净标签页上两轮复现：错误密码都会弹出「用户名或密码错误」且停留 3 秒**。你那边看不到提示，最可能是登录页还跑着修复前的旧代码——请 **Ctrl+F5 强制刷新登录页**再试。
- 另发现一个真正会「毫无反应」的死角：滑块未通过时登录按钮是**禁用态**，点击完全无反馈。而每次登录失败（或刷新页面）后滑块都会重置，若没有重新拖滑块就点登录，正是这种静默无反应。

## 修改（3 个文件，小改）
1. `AdminLogin.vue`：登录按钮不再禁用（移除 `:disabled="!slideOk"`）；`onSubmit` 里滑块未通过时 `ElMessage.warning(t('admin.login.slideFirst'))` 并返回——把静默无反应变成明确提示
2. i18n zh/en 新增 `admin.login.slideFirst`：「请先完成滑块验证」/「Please complete the slider verification first」（§10 双语）

## 验证与收尾
1. 浏览器验证三态：未过滑块点登录 → 警告提示；错误密码 + 滑块 → 「用户名或密码错误」；正确密码 → 登录成功
2. `npm run build` 通过；提交推送
