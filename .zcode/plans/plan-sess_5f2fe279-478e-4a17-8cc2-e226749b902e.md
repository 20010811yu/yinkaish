# 修复：富文本编辑器全屏时「已发布」开关浮在上层

## 根因
wangEditor 全屏通过给工具栏+编辑器的容器加 `w-e-full-screen-container` 类（`position: fixed`）实现，但该容器没有足够 z-index；编辑器位于 el-dialog 内，弹框 overlay z-index ≈ 2004，导致同在弹框表单里的「已发布」el-switch 等控件绘制在全屏编辑器之上（用户截图中部的绿色开关）。

## 修改（1 处，纯 CSS）
`src/components/admin/RichEditor.vue` scoped 样式追加：
```css
.rich-editor.w-e-full-screen-container,
.rich-editor :deep(.w-e-full-screen-container) {
  z-index: 3000; /* 高于 el-dialog 的 ~2004,全屏时盖住表单 */
}
```
两个选择器兼容「全屏类落在我们根节点」与「落在 wangEditor 内部节点」两种 DOM 形态。

## 验证与收尾
1. 浏览器实测：打开编辑弹框 → 点全屏 → 确认开关不再浮层、全屏正常显示与退出
2. `npm run build` 通过
3. 提交推送（纯样式层级修复，记忆库无需更新）
