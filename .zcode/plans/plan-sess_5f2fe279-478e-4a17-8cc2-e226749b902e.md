# 产品弹框图片预览优化：主图加高完整显示 + 画廊统一缩略图 + 点击放大

## 修改（1 个文件：`AdminProducts.vue`）
1. **主图预览**：从 100px 高小图改为 `260px` 高、宽占满的 `el-image`（`fit=contain` 完整显示不裁剪，浅灰底衬），加 `preview-src-list` + `preview-teleported`——**点击放大**全屏查看
2. **画廊统一预览**：缩略图不再只显示已上传的，改为统一预览项（computed `galleryItems`）= 已上传路径 + 素材库选中项（经 `ol2iGalleryByName` 解析成 URL），每项 80×80 缩略图 + 移除按钮（分别操作对应来源数组）
3. **画廊点击放大**：每个缩略图带 `preview-src-list`（全集）+ `initial-index`（从点击那张开始）——放大后可左右翻看全部画廊图

## 验证与收尾
1. 浏览器验证：YK-FC-3C 主图预览加高完整显示、点击放大；YK-OL-2I（画廊 5 张素材图）缩略图预览、点击放大可翻页；移除按钮来源正确；取消不保存
2. `npm run build` 通过；提交推送（纯管理端 UI 增强，记忆库无需更新）
