# 新闻分类改为「下拉选择 + 手动输入新分类」

## 方案
`AdminNews.vue` 编辑/新增弹框的「分类」字段从纯输入框换成 `el-select`（`filterable allow-create default-first-option`）：
- **下拉选项** = 现有新闻的 `tag_zh` 去重排序（computed `tagOptions`，随列表数据自动更新）——无需新建分类表
- **手动输入** = allow-create 允许键入新分类回车即创建，`default-first-option` 支持输入后直接回车
- 与荣誉/产品管理页图片下拉同一交互模式，行为一致
- i18n 新增 `admin.fields.tagHint` 占位文案：「选择现有分类或输入新分类」/「Select an existing tag or type a new one」（§10 双语）

## 验证与收尾
1. 浏览器验证：打开编辑弹框 → 分类为下拉框，选项含现有分类（公司动态/技术迭代/项目交付/展会活动/质量体系）；键入新分类可创建；保存后新分类出现在列表与下拉选项中
2. `npm run build` 通过；提交推送（小改动，记忆库无需更新）
