# 修复：管理端登录失败提示错误的「会话过期」文案

## 诊断结论（已浏览器复现）
登录失败**有提示，但内容错误**：错误密码提交后弹出「登录已失效，请重新登录」。原因是 `src/api/admin.js` 的 `request()` 把**所有** 401 都当会话过期处理，登录接口自己的 401（服务端返回 `{error:'invalid credentials'}`，即用户名或密码错误）也被吞掉，真实原因没能显示。

## 修改（3 个文件）
1. **`src/api/admin.js`**：401 会话过期分支排除登录接口——`if (res.status === 401 && path !== '/api/admin/login')`；登录的 401 落入通用分支抛出服务端 `error`
2. **`src/views/admin/AdminLogin.vue`**：catch 里把服务端英文标识 `invalid credentials` 映射为双语提示（其余错误如网络失败原样展示）
3. **i18n zh/en**：新增 `admin.login.invalid`——zh「用户名或密码错误」/ en「Invalid username or password」（§10 双语规范）

## 验证与收尾
1. 浏览器复现同路径：错误密码 + 滑块通过 + 提交 → 应弹出「用户名或密码错误」、停留登录页、滑块重置
2. 正确密码登录成功路径不回归
3. `npm run build` 通过
4. 提交推送（小缺陷修复，errorlog 是否入档视验证中是否踩坑而定）
