## 富文本改造（提交 B）

### 1. 新增依赖（仅 /admin 懒加载分包，不增前台体积）
- `@wangeditor/editor` + `@wangeditor/editor-for-vue`（Vue3 绑定，v5 next）
- AdminNews 是懒加载路由，编辑器 chunk 只在进管理后台时加载

### 2. 新建封装组件 `src/components/admin/RichEditor.vue`
- v-model 绑定 HTML 字符串；工具栏精简：标题/加粗/斜体/删除线/下划线、有序/无序列表、引用、链接、清除格式（**不含图片上传**——图片走现有素材文件名机制，避免 base64 撑爆库）
- 菜单语言跟随 i18n locale（zh-CN/en），`editorConfig.MENU_CONF` 无需上传配置
- 组件内 `onBeforeUnmount` 销毁编辑器实例防内存泄漏

### 3. `AdminNews.vue` 换编辑器
- 正文 `el-input textarea` → `<RichEditor v-model="form.content_zh" />`，校验逻辑不变（仍必填 title_zh；content 必填性保持现状）

### 4. 前台 `NewsDetail.vue` 渲染端兼容
- `content` 以 `<` 开头 → `v-html` 富文本渲染（补 `:deep()` 样式：p/ul/ol/blockquote/a/strong 间距与颜色）
- 否则沿用现有 `split('\n')` 纯文本分段渲染（存量 12 条零迁移）
- 信任边界说明：内容仅来自管理端登录后写入，不做 DOMPurify 消毒（不新增第二个依赖）

- `npm run build` 必须通过；浏览器实测：管理端编辑正文（加粗/标题/列表）保存 → 前台新闻详情页富文本渲染正常、老新闻纯文本渲染不回归
