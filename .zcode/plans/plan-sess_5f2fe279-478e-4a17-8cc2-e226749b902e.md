# 登录失败信息内嵌显示在登录界面（不自动消失）

## 背景
上一轮修复后失败信息只有顶部 Toast 提示（3 秒自动消失），用户要求失败信息直接显示在登录界面上。

## 修改（1 个文件：`src/views/admin/AdminLogin.vue`）
- 滑块与登录按钮之间加常驻错误提示：`<el-alert v-if="loginError" type="error" show-icon>`，登录失败（catch 分支）时设置文本，不自动消失
- 重新输入用户名/密码时自动清除（watch 表单字段）
- 失败时保留顶部 Toast（内嵌 + Toast 双提示）；「请先完成滑块验证」维持 Toast 不变（属操作引导）
- 样式：`.login__error { margin-bottom: 14px }`
- 复用现有 `admin.login.invalid` 双语文案，无需新增 i18n key

## 验证与收尾
1. 浏览器验证：错误密码 → 红色警示条常驻显示「用户名或密码错误」，Toast 同时出现；重新输入任一凭据 → 警示条消失；正确密码 → 登录成功
2. `npm run build` 通过；提交推送（纯 UI 增强行为，记忆库无需更新）
