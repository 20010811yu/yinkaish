# 产品弹框：新增「所属分类」下拉 + 「产品标签」可选可输

## 背景（已与用户确认）
产品编辑弹框中现标着「分类」的字段存的其实是**产品标签**（立冲长边等）；产品线分类（光伏边框自动生产线等）目前只能在对应区块下新增产品，弹框内不可改。

## 修改（`AdminProducts.vue` + i18n）
1. 产品弹框新增「所属分类」下拉：选项 = 产品分类表（`cats`，6 条产品线），绑定 `category_id`，可切换产品所属分类并保存（后端 `productFields` 白名单本就含 `category_id`，无需动后端）
2. 原「分类」字段正名为「产品标签」，换 `el-select`（`filterable allow-create default-first-option`）：选项 = 现有产品标签去重，可手动输入新标签
3. 分类区块下产品小表格的「分类」列头同步改为「产品标签」
4. i18n 新增双语 key：`category`（所属分类/Category）、`productTag`（产品标签/Product tag）、`productTagHint`（选择现有标签或输入新标签）

## 验证与收尾
1. 浏览器验证：YK-6A 弹框 → 所属分类下拉列出 6 个产品线分类且选中正确；产品标签下拉可选可输新标签；改标签保存后列表与选项更新，再还原；**换所属分类保存→产品跨分类移动→改回还原**
2. `npm run build` 通过；提交推送（测试数据还原，记忆库无需更新）
