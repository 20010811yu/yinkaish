# 产品图片本地上传（主图单张 + 画廊多张）+ 服务端自动重命名

## 架构
后端新增受 JWT 保护的上传接口，图片存 `server/uploads/`（Express 静态托管），DB 存 `/uploads/xxx.png` 路径；前台水合时「根路径/绝对 URL 原样用，否则走素材文件名映射」双轨解析。

## 自动重命名（本次明确要求）
上传时**服务端一律自动重命名**，不保留原始文件名（避免中文/空格/超长名与重名冲突）：
- 命名规则：`img-<yyyyMMdd-HHmmss>-<4位随机>.<安全扩展名>`（如 `img-20260930-143025-7f3k.png`）
- 时间精确到秒 + 随机后缀保证唯一；扩展名白名单映射（jpg/jpeg/png/webp），原扩展名非法一律拒绝
- 接口同时返回 `name`（新文件名）与 `url`（`/uploads/<新文件名>`），前端存 url

## 后端（server/）
1. 新依赖 **multer**（multipart 解析，express 生态标准件）
2. `server/src/index.js`：`/uploads` 静态托管（目录启动时 mkdirSync recursive）
3. `POST /api/admin/upload`（requireAdmin 保护）：multer diskStorage 按上述规则命名；白名单 png/jpg/jpeg/webp；单文件 ≤5MB
4. `.gitignore` 增加 `server/uploads/`

## 前端管理端（AdminProducts.vue）
1. 主图：加 `el-upload` 单张（picture 预览，成功后 `prodForm.image = res.url`），原素材下拉保留、占位改「或从素材库选择」；预览 `urlOf` 兼容 `/uploads` 路径
2. 多图画廊：加 `el-upload` multiple，逐个追加；保存时 `gallery = 素材选中项 + 已上传路径` 合并；编辑回显把 `/uploads` 开头的值拆到已上传列表、其余进素材多选
3. 上传带 Authorization 头；前端预校验类型/大小与服务端一致

## 解析兼容（双轨）
1. `src/data/assets.js` 导出 `resolveImage(v, map)`：`^/` 或 `^https?://` 原样返回，否则查映射
2. `src/api/data.js` 四处图片解析改走 `resolveImage`
3. `vite.config.js` dev 代理增加 `'/uploads': 'http://localhost:3001'`
