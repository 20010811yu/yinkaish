# 修复：刷新 /admin 页面闪现官网导航/页脚

## 根因（已诊断）
`src/main.js` 先 `app.mount()` 后路由才解析，Vue Router 4 首次导航完成前 `route.path` 为初始 `'/'`，`App.vue` 的 `isAdmin` 判 false → 官网 Navbar/Footer 先渲染一帧，等 AdminLayout 懒加载分包就绪后才切换消失。

## 修改（1 处，1 行）
`src/main.js`：挂载前等首次路由解析完成——
```js
router.isReady().then(() => app.mount('#app'))
```
深链接刷新（/admin/* 及其他懒加载页）首帧即为正确路由，代价仅是挂载推迟几十毫秒。
