# 修复：删除确认框无样式缩在左上角 + 按钮英文 OK/Cancel

## 根因（已诊断）
1. **位置不对 = 样式完全缺失**：`ElMessageBox` 是函数式组件，不经过 unplugin 模板按需引入，其 CSS（含 `position:fixed`、背景、按钮样式）从未被引入 → 确认框以裸 HTML 形态渲染在文档流左上角。前台 Contact/Careers 的 `ElMessage` 也有同样的潜在缺失。
2. **按钮英文**：全站未配置 Element Plus locale（防回归清单 #3 的既有欠账），EP 内置文案（MessageBox 的 OK/Cancel、分页等）回落英文默认值。

## 修改
1. **`src/main.js`**：全局显式引入 `message` 与 `message-box` 的样式 css（§8.2 官方做法；全站去重加载，前台表单 Toast 一并修好）
2. **`src/App.vue`**：外层包 `<el-config-provider :locale="epLocale">`，locale 跟随 i18n（zh-cn / en）——MessageBox 按钮变「确定/取消」，同时满足防回归 #3

## 验证与收尾
1. 浏览器验证：管理端点删除 → 确认框居中、遮罩+完整样式、按钮为「确定/取消」；点取消不删除；首页联系表单 Toast 样式正常（回归）
2. `npm run build` 通过（关注主包 css 增量，预计 gzip 数 KB）
3. errorlog 记 ERR-013（函数式组件样式缺失 + EP locale 欠账）；progress/activeContext 同步；提交推送
