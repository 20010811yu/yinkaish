# 光伏面板改为分阶段绘制动画(每次进入视口重播)

用户要求动画按「描边 → 画分割线 → 填色」三阶段呈现,且每次滚入屏幕自动重播。现有 IntersectionObserver 已在进/出视口时增删 `.revealed`(天然支持重播),只需重排 CSS 动画时序(仅改 CtaVisual.vue 的动画部分):

## 三阶段时序(进入视口后)
1. **①描边(0-1.1s)**:面板外框、铝边框板厚、支架立柱、地线依次 stroke 描边绘制
2. **②分割线(1.1-1.9s)**:电池片分栅线描边绘制(此前是被禁用的)
3. **③填色(2.0-2.6s)**:深蓝电池片顶面+铝边框淡入;染色层(蓝深呼吸)从进入视口即与太阳同步脉动,填色显现后自然衔接

离开视口时所有状态复位(dashoffset 归位、填色透明),再次进入即完整重播。reduced-motion 用户仍看到静态完成态。
