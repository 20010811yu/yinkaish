# 日历与头条卡片分离、去外层边框

## 现状
日历嵌在头条 `article.featured` 卡片内部，整卡一条边框把「最新动态」和日历框在一起。

## 改动(仅 News.vue)
1. **结构拆分**：外层改为 `.featured-row`（grid 两列 1.4fr/1fr、gap 24px）：
   - 左：`<article class="featured">` 只含文字内容（白底+边框+圆角独立成卡）
   - 右：`<div class="cal-panel">` 绿色渐变面板 + 迷你日历，独立成块，与左卡完全分离（各自圆角，中间留缝）
2. **样式迁移**：`.featured` 去掉双列 grid；面板样式移到 `.cal-panel`；≤1024 单列（日历排到文字下方）；≤768 跟随
3. 点击交互不变：左卡点击进头条详情；日历点击冒泡已阻断、互不影响

## 验证
浏览器目测两块分离效果 + 点击行为 + 375 宽度 + build + 推送。
