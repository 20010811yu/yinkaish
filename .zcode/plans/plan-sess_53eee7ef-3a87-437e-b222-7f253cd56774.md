# 光伏面板动效调整:去白影 + 颜色随太阳呼吸渐变

## 改动(仅 CtaVisual.vue)
1. **删除白影闪烁**:移除 `panel__shine` 元素及其 `cta-shine` 动画/样式
2. **太阳呼吸重定义相位**:0% 太阳最小最暗(core scale 0.85、亮度 1)→ 50% 太阳最大最亮(scale 1.1、亮度 1.35)→ 100% 回落;射线同步(暗 0.3 ↔ 亮 1)
3. **面板颜色随呼吸渐变**:面板面片上新增同形状的染色层 `panel__tint`(深藏青 #0d2c4d),opacity 与太阳同一 3s 节奏——太阳最大最亮时(50%)opacity 0.4(蓝最深),太阳最小时(0%)opacity 0.05(蓝最浅);reduced-motion 用户看到固定中等深度
4. 其余(支架、梯形几何、色块背景、进场描边)全部不动

## 验证
浏览器 HMR 目测太阳与面板同步呼吸;build 通过;记忆库一笔;提交推送。
