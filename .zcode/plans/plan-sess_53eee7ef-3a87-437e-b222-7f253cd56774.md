# 光伏面板改为正对屏幕、自上而下倾斜的视角

## 设计
面板不再用侧视斜透视，改为**正面视角 + 顶部向后倾**的构图（类似真实电站宣传图）：

1. **面板主体**：正面梯形（下宽上窄，模拟从上往下倾斜的透视）——底边 (100,170)-(290,170)，顶边 (120,95)-(270,95)，深蓝电池片渐变铺满
2. **分栅网格**：3 条纵栅+2 条横栅，端点按梯形边线线性插值精确计算，铺满整面（含铝合金外框描边+底部板厚）
3. **支架**：面板底部两根立柱（x=130/x=260）落地(y=212)+底部横梁，简单真实的正面支架
4. **地面投影**：扁椭圆移到面板正下方
5. 太阳/呼吸动画、光泽扫过、色块背景层、reduced-motion 全部不动

## 实施
仅改 `CtaVisual.vue` 的面板 SVG 图形与光泽形状；验证：浏览器目测 + build + 记忆库 + 推送。
