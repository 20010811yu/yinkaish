# 「为什么选择寅铠」布局重设计：融入动画元素

## 设计方向
保持现有信息（左文右图 + 四条优势），全面融入全站已有的动画语言，让整块"活"起来，布局微调为三行节奏：

1. **标题区**：标题下电路连线 SVG 描边绘制（复用首页 partners/adv 的 wire-draw 模式），端点圆点持续脉冲
2. **左列文字**：绿标语 + 描述 + 大数字（±0.1mm/98% 已有计数动画）——不变
3. **右侧城市图**：新增装饰层——图片容器四角"取景框"角标描边进场 + 图上叠加缓慢移动的光点/扫描线（模拟智造城市夜景的动效），图片容器轻微视差已有，再加一层 hover 微倾斜
4. **四条优势**：每个条目前加一个小 SVG 图标（积淀=齿轮、领先=曲线上升、检测=扫描框、国际=地球，线性描边风格），随 [data-reveal] 进入时逐个描边绘制 + 错峰入场（现有 data-reveal-delay 已支持），数字 01-04 改为描边数字缓现
5. **整体节奏**：进入视口 → 标题/连线先画 → 文字淡入 → 图四角+光效 → 四优势错峰描边入场

## 实施范围
仅改 `Home.vue` 优势板块的模板装饰元素与 scoped 动画 CSS（复用现有 reveal/wire-draw 基建），不动数据与文案。

## 验证
浏览器目测动画节奏；四档宽度零溢出；build；记忆库；推送。
