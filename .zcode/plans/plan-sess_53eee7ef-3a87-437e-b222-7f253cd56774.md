# 支架高级化:铝型材导轨 + 斜撑立柱 + 接地底脚

## 设计(参照真实电站铝支架)
把现在两根细绿线换成有质感的结构件(全部填充+描边,不再纯线条):
1. **底部导轨**:面板下方一条铝色(银白渐变)横梁贯穿两柱(118-272,厚 5px)
2. **斜撑立柱**:左右两根向外张开的斜腿(A 字形张力感),铝色填充+绿描边,上窄下宽
3. **接地底脚**:两块小矩形底脚压在地线上,落地稳固
4. 材质复用面板边框的 `pvEdge` 银白渐变 + 品牌绿描边,与面板语言统一

## 动画
支架保留与面板同步的描边(0-0.9s);填充在边框画完后淡入(0.9s 延迟,与板厚一致);进出视口重播、reduced-motion 静态不变。

## 实施
改 `CtaVisual.vue`:替换 `panel__leg` 路径为 4 个结构件(导轨/左斜腿/右斜腿/两个底脚,共用 panel__leg 类);CSS 给 `.panel__leg` 加填充与淡入。验证:浏览器目测 + build + 记忆库 + 推送。
