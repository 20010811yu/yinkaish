# 联系表单接入 Netlify Forms（用户已配置好两个收件邮箱的通知）

用户确认已在 Netlify 站点的 Forms → Settings and notifications 中添加 lukecao@ykautomus.com 与 lujiacao@163.com 两个邮件通知。现在落地代码侧改动：

## 改动

1. **`index.html` 追加隐藏静态"影子表单"**（`display:none`，`name="contact"` + `data-netlify="true"`，含 name/email/phone/message 四个 input）。Netlify 在部署时解析静态 HTML 注册表单；Vue SPA 的表单是运行时渲染的，没有影子表单 Forms 面板就不会识别。

2. **`src/views/Contact.vue`**：
   - `el-form` 加 `name="contact"`；
   - `submit` 改为校验通过后 `fetch('/', { method: 'POST', headers: {'Content-Type':'application/x-www-form-urlencoded'}, body: new URLSearchParams({ 'form-name': 'contact', ...form }) })`；
   - 成功：保留现有"提交成功"提示并清空表单；失败：`ElMessage.error` 提示（i18n 新增 `contact.form.fail` 中英双语）。

3. **构建验证**：`npm run build` 通过，并确认 `dist/index.html` 含影子表单、Contact 页提交逻辑正确。

4. **P4/P5 收尾**：更新 activeContext.md（Netlify Forms 接入）、techContext.md（部署小节补充：表单仅在 Netlify 生效，GitHub Pages 版提交会失败提示）；提交推送，触发 Netlify 自动部署。

5. **交付验证说明**：部署完成后在线上表单提交一条测试留言，确认 Forms 面板出现记录、两个邮箱收到邮件。
