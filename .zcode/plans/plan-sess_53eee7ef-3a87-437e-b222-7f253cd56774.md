# 加大光伏板电池面展示面积

反馈:蓝色电池面可见面积太少(进深方向太窄,像薄板)。改法(仅调 CtaVisual.vue 中面板几何的进深向量,倾角左低右高与支架结构保持):

1. **大板 A**:进深向量从 (44,-26) 加大到 (62,-36),顶面从窄条变为宽阔的平行四边形(蓝色面积约增 40%),分栅线端点按新几何重新插值计算、精确铺满
2. **小板 B**:进深同步从 (26,-14) 加大到 (34,-20),分栅线重算
3. 支架立柱/斜撑端点按新板底位置微调,保证腿顶仍接在板底
4. 光泽扫过形状同步更新;太阳/呼吸/色块背景/reduced-motion 全部不动

验证:浏览器截图目测 + 四档宽度零溢出 + build 通过 + 记忆库 + 推送。
