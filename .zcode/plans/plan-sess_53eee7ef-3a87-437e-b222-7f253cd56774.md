# 新闻详情页重设计：去绿色横幅 + 文章式布局

## 现状
NewsDetail 使用全局 `.page-hero` 绿渐变横幅（About/Services/News 等 6 页共用，**不动全局样式**，仅改 NewsDetail 自己的头部），正文区只有一个段落+返回按钮，缺乏文章感。

## 新布局（仅改 NewsDetail.vue，scoped 样式）
1. **页头（浅色底 `--c-bg-soft`，左对齐）**：
   - 顶部一行：「← 返回列表」文字链接 + 右侧新闻分类标签（绿色胶囊 chip）
   - 大标题（深色、clamp 字号、左对齐）
   - 元信息行：发布日期（含日历小图标）· 来源分隔样式
2. **正文**：限宽 720px 居中，16-17px/1.95 行高，首段无额外边距；正文按 `\n` 拆分为多段渲染（现在是一整段）
3. **文末**：分隔线 + 返回按钮居中；底部轻微留白
4. 保留 data-reveal 式淡入（可选加轻量进场）

## 验证
浏览器目测中英两语言、一条新闻详情；375 宽度无溢出；build；记忆库；推送。
