# projectbrief.md — 项目事实来源

## 项目定位
"银凯科技"公司官网(占位品牌名,内容可整体替换):中英双语企业展示站,展示公司简介、业务与产品、团队、新闻动态、招聘与联系方式。

## 目标
1. 现代简洁、响应式的企业官网,体验专业
2. 中英双语完整覆盖,语言偏好持久化
3. 可直接部署(静态构建产物,适配 GitHub Pages 等静态托管)

## 范围边界
- 纯前端展示站,无后端、无真实登录/支付;联系表单仅前端交互提示
- 新闻/职位/团队均为 `src/data/` 占位数据,后续由真实内容替换

## 阶段
- 阶段 1(当前):项目初始化 + 全部 8 个页面(Home/About/Services/Team/News/NewsDetail/Contact/Careers)+ 双语 + 响应式
- 阶段 2(待定):真实内容替换、部署上线
