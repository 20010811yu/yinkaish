# productContext.md — 为什么做、为谁做

## 目标用户
- 潜在客户与合作方:了解公司实力、业务与案例
- 求职者:了解团队文化与在招职位
- 中英文访客各占一定比例,需无缝切换

## 体验目标
1. 3 秒内让访客明白公司是做什么的(首页 Hero 直接传达定位与 CTA)
2. 任意页面 2 次点击内可到达主要栏目
3. 移动端体验与桌面端同等可用(汉堡导航、单列布局)
4. 切换语言后全站(含组件库内置文案)立即跟随,刷新不丢失

## 工作方式
- SPA + 前端路由,页面间无刷新跳转
- 数据驱动渲染:新闻、职位、团队等来自 `src/data/`,组件不硬编码
